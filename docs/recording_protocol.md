## Setup
- Tascam DR-70D in the center of the table (built-in omni pair).
- Two ESP32 boards on the table; note their positions.
- One DJI Mic 2 lav per speaker.
- All devices at 16 kHz or higher; note each device's settings.

## Each session
1. Start all devices.
2. One loud clap visible to everyone (used to align devices).
3. 5-10 min of natural Mandarin-English conversation.
4. Stop all devices; record metadata below.
